# Isleta 1.1.0

Isleta introduces itself on first launch, notifications open the island and show what they say, and
the island stays at the notch through every kind of space switch.

## New

- **A setup guide the first time you open Isleta.** Four screens: what the notch is about to start
  doing, the one permission Isleta ever asks for, launch at login, and where to find the island.
  Leave it at any point — it does not come back. In the status menu as **Open Setup Guide**.
- **Notifications open the island** and show the whole message — who it is from and what it says,
  not the first two lines. It closes itself a few seconds later, unless you opened the island
  yourself, in which case it stays yours.
- **Swipe up with two fingers to close an open island.** Up is up, whichever way you have "natural
  scrolling" set. Swiping sideways still stows the island's content.
- **Export Logs…** in the status menu writes a single file, wherever you choose, with everything
  needed to look into a problem. It offers to show you the file afterwards.
- **Isleta keeps a log** at `~/Library/Logs/Isleta` — events only, never track titles or
  notification text, so the export is safe to send to a stranger. It never grows past a few
  megabytes. For more detail: `defaults write com.tryisleta.isleta VerboseLogging -bool YES`.

## Improved

- **The island opens to the size of what it is holding.** A wake greeting opens short, a
  notification opens as far as its message needs, and the player is unchanged.
- **A notification no longer clips the app's name** into a 40-point sliver where "Messages" did not
  fit. VoiceOver still reads it out.
- **Settings is five pages, not seven.** Shortcut is now a card in General. System held one switch
  that could never be turned on and is gone — what it explained is under Sources, beside the thing
  it is about.
- **Sources reads as one list**, instead of four headings each repeated by the switch beneath it.
- **Island opacity appears only if you have a display without a notch**, which is the only place it
  has ever done anything.
- **Copy Diagnostics has left the status menu.** Export Logs… carries the same report and the
  history behind it.

## Fixed

- **The island stays at the notch when you switch spaces** — desktops, fullscreen apps, trackpad
  swipes and ⌃← / ⌃→ alike. No wait, no bounce, no blip, and Input Monitoring is no longer involved.
- **Now Playing said the same sentence twice** in Settings — once as its description, once as its
  status.
- **The settings sidebar drew page names through the Isleta icon** and the version number when you
  scrolled it.

## Requirements

macOS 26 or later, on Apple Silicon. Displays with a real notch get the island; a Mac with none gets
a synthesized island on the primary display.

## Known limitations

- **Brightness has no HUD.** macOS offers no public way to read display brightness on Apple Silicon.
- **Apple's own HUDs are not replaced.** Isleta shows its own alongside them; the switch that
  suggested otherwise is gone.
- **The island sits above Mission Control.** In a real notch it covers nothing; a synthesized island
  can cover the centre of the space labels.
- **A burst of notifications opens the island once for each.** Grouping them is a later release's
  job.
- **Playing music costs about 0.4% CPU**, against an internal 0.3% budget. Everything else is inside
  budget.
