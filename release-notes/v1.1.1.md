# Isleta 1.1.1

A fix for 1.1.0: the General page in Settings could not be clicked.

## Improved

- **The Notifications row says where you stand in three words** — "Granted." or "Not granted yet." —
  instead of a paragraph restating the description directly above it.

## Fixed

- **General could not be clicked in Settings.** 1.1.0 put a blur behind the sidebar's icon and
  version number so the page names pass behind them when the list scrolls. It reached 28 points too
  far down, over the first row, where it quietly swallowed clicks — so anyone who navigated to
  another page could not get back to General.

## Requirements

macOS 26 or later, on Apple Silicon. Displays with a real notch get the island; a Mac with none gets
a synthesized island on the primary display.

## Known limitations

- **Brightness has no HUD.** macOS offers no public way to read display brightness on Apple Silicon.
- **Apple's own HUDs are not replaced.** Isleta shows its own alongside them.
- **The island sits above Mission Control.** In a real notch it covers nothing; a synthesized island
  can cover the centre of the space labels.
- **A burst of notifications opens the island once for each.** Grouping them is a later release's
  job.
- **Playing music costs about 0.4% CPU**, against an internal 0.3% budget. Everything else is inside
  budget.
